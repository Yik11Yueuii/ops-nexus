# 星云科技 · 订单服务部署手册 v1.0

> 虚构企业演示资料。该版本保留用于后续版本对比，不代表生产操作指令。

## 服务信息
服务名称：order-service。负责人：星云订单研发组。
依赖：MySQL 订单库、Redis 缓存、API 网关。
部署前确认变更审批、制品版本和回滚包已准备。

## 环境检查
应用运行环境使用 Java 21。启动前检查数据库和 Redis 连通性。
数据库连接池最大连接数为 10，获取连接超时为 30 秒。
Redis 最大连接数为 8，连接等待超时为 2 秒。

## 发布步骤
1. 在测试环境验证订单创建和状态查询。
2. 记录当前运行版本，保存应用配置备份。
3. 部署新版本并观察健康检查、日志和业务指标。
4. 健康检查连续通过后逐步恢复流量。

## 风险提示
连接池耗尽时先确认异常来源，不直接扩大连接池。
失败时按照发布与回滚规范恢复上一稳定版本。
