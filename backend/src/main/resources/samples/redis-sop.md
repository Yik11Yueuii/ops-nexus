# 星云科技 · Redis 连接池耗尽排障 SOP

> 虚构演示案例；系统只能给出辅助建议，不能自动执行运维命令。

## 适用现象
order-service 日志出现连接池等待超时，订单接口耗时升高。
仅凭超时日志不能断言 Redis 宕机，需结合连接状态和近期变更。

## 排查顺序
1. 确认故障服务、开始时间、错误日志及影响范围。
2. 查询当前服务版本和最近发布记录，比较错误发生时间。
3. 检查连接等待数、连接归还情况以及 Redis 响应延迟。
4. 排查异常分支是否遗漏连接释放，核对连接池配置是否与部署手册一致。
5. 检索历史相似故障，逐项验证可能原因。

## 常见原因
应用连接未及时归还；Redis 响应变慢；突发流量超过连接池容量。
这些是待验证原因，不能在缺乏指标时当作已确认根因。

## 处理建议与升级
保留日志和发布信息，联系值班负责人评估限流或回滚。
不要直接清空缓存、重启数据库或无上限扩容连接池。
恢复后补充根因、处理过程和预防措施到故障复盘。
