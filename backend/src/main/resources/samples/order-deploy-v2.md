# 星云科技 · 订单服务部署手册 v2.0

> 虚构企业演示资料。本版新增连接池观察和灰度检查要求。

## 服务信息
服务名称：order-service。负责人：星云订单研发组。
依赖：MySQL 订单库、Redis 缓存、API 网关。

## 环境检查
运行环境使用 Java 21。配置从受控环境变量读取，禁止把凭据写入日志。
数据库连接池最大连接数调整为 20，获取连接超时仍为 30 秒。
Redis 最大连接数调整为 16，连接等待超时调整为 3 秒。
调整连接池前须核对数据库总连接预算和 Redis 客户端数量。

## 发布步骤
1. 在测试环境验证订单创建、状态查询及幂等请求。
2. 备份当前制品与配置，记录应用版本和依赖版本。
3. 先将少量流量切入新版本，观察错误率、接口耗时和连接等待数。
4. 健康检查通过且连接等待数未持续增长后扩大流量。
5. 发布完成后保留观察窗口并登记发布记录。

## 风险提示
若出现连接池等待超时，先检查慢查询、连接泄漏和近期发布。
不得在未核对资源预算时继续增加连接池。
回滚前确认数据库变更是否向后兼容，破坏性迁移需人工评估。
