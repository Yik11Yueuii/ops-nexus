# OpsNexus 演示与验收清单

更新时间：2026-09-08。功能冻结：9 月 10 日；汇报：9 月 14 日上午。

## 八分钟演示主线

1. 管理员登录工作台，说明星云科技为虚构演示企业。
2. 在“知识文档”展示 PDF/DOCX/Markdown/TXT 上传能力、部署手册 v1/v2、处理与发布状态。
3. 在“知识助手”询问 Redis 排障问题，展示流式回答、可信等级、引用原文与会话反馈。
4. 在“业务查询”查询 `order-service` 最近发布，指出实际调用固定工具而非自由 SQL。
5. 在“故障诊断”输入 Redis 获取连接超时，展示 SOP、最近发布、历史故障与待验证假设。
6. 在“版本对比”比较部署手册 v1/v2，展示连接池参数和发布流程变化。
7. 用证据不足问题触发拒答，在“缺口雷达”展示自动聚合和处理。
8. 在“数据分析”询问“最近 30 天故障次数最多的服务”，展示生成 SQL、AST 审核、100 行/3 秒、结果及审计。

## 冻结前验收命令

```powershell
$env:JAVA_HOME='E:\jdk\jdk21'
$env:PATH="$env:JAVA_HOME\bin;$env:PATH"
mvn -f backend/pom.xml test
cd frontend
npm.cmd run build
npx.cmd playwright test
```

浏览器回归前须启动前后端，并设置 `DEMO_ADMIN_PASSWORD`、`DEMO_USER_PASSWORD`。真实模型用例仅发送虚构演示内容。

## 安全讲解要点

- 普通用户不接触 SQL，只能调用后端固定只读工具。
- 管理员 SQL 仍不被信任：模型只负责生成候选，后端 AST 是最终裁决者。
- SQL 查询账号只有三张演示业务表的 SELECT 权限，且有行数、超时和审计限制。
- 文档证据不足时拒答；AI 建议和待验证假设不能冒充企业事实。
- 密钥仅从本机环境加载，不进入前端、数据库审计或版本库。
