# OpsNexus 现场演示运行手册

## 1. 演示前一天

1. 确认 `scripts/local-env.ps1` 存在，密钥与演示账号密码不出现在截图、PPT 和版本库。
2. 启动本机 Redis；Redis 不可用不会阻塞核心演示，但系统状态会显示降级。
3. 启动前后端后执行 `scripts/check-demo.ps1`，所有必需项应为 PASS。
4. 执行后端测试、前端构建和 Playwright 回归；保留 `runtime/screenshots` 作为离线展示备份。
5. 关闭无关软件通知，浏览器缩放恢复 100%，准备管理员和普通用户两个标签页。

## 2. 启动顺序

```powershell
# 项目根目录：启动本机 Redis
.\scripts\start-redis.ps1

# 终端一：项目根目录
.\scripts\start-backend.ps1

# 终端二
cd frontend
npm.cmd run dev

# 终端三：项目根目录
.\scripts\check-demo.ps1
```

访问 `http://127.0.0.1:5173`。不要在投屏画面中打开 `scripts/local-env.ps1`。

## 3. 八分钟讲解节奏

- 0:00–0:40：产品定位、虚构企业与技术栈。
- 0:40–1:30：工作台和版本化知识文档。
- 1:30–2:40：带引用、可信等级和拒答边界的 RAG 问答。
- 2:40–3:20：普通用户固定 Tool Calling，强调“不生成 SQL”。
- 3:20–4:40：故障诊断组合 SOP、发布记录和历史故障。
- 4:40–5:30：文档版本对比与风险提示。
- 5:30–6:10：低证据拒答进入知识缺口闭环。
- 6:10–7:30：管理员 Text-to-SQL 的 AST、白名单、只读账号、限行、超时与审计。
- 7:30–8:00：AI 限流、调用日志、测试结果和项目价值总结。

## 4. 现场故障降级

| 情况 | 处理 |
|---|---|
| DeepSeek 超时 | 展示已保存的历史会话和 `assistant-desktop.png`，说明调用有超时与友好错误处理 |
| 百炼不可用 | 不现场上传向量化；使用已经发布并持久化的向量快照 |
| Redis 未启动 | 说明当前为有限降级，H2 中的文档、会话和审计不受影响 |
| Text-to-SQL 模型输出被拒 | 将其作为安全演示，展示审计中的 REJECTED；再使用固定演示问题 |
| 浏览器异常 | 刷新并重新登录；必要时展示 `runtime/screenshots` 中的回归截图 |

## 5. 演示后

不要临时修改业务代码或数据库。记录问题，9 月 10 日冻结后只做缺陷修复、测试和汇报材料调整。
